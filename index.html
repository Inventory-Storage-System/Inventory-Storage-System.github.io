📚 What this is

A shared tracker for your physical units. Each unit has a model, serial, notes, a location (shelf + bay), and a type — Inventory or Demo. Everyone with the link sees the same live data.

🔍 Finding a unit

On the Shelves page, type a model, serial, or note in the search box. Matching units light up and pulse, everything else dims, and the view jumps to the first match — showing exactly which shelf and bay it's in. You can also hit 📍 Locate on any row in the Master List.

📋 Master List

The full table of every unit — the source of truth. The shelf wall is just a visual of it. Anyone can browse and filter it; only Admin can add, edit, or delete.

📤 Loans & removing units

On the Master List (Admin), each unit has actions:

  • 📤 Loan out (demo units only) — mark a demo unit as out on loan. It leaves its bay and moves to the 📤 On loan area on the shelf page with an OUT marker, and remembers its last shelf/bay. You can note who it's out to and since when.
  • 📥 Return — bring a loaned unit back; it drops into its remembered shelf/bay (or Unassigned if that spot is gone).
  • 🗑 Remove — take a unit off the list. Choose Sold / disposed to delete it completely, or (for demo units) Out on loan to keep it in the system.

Inventory units don't go out on loan — they can only be removed if sold/disposed.

🔒 Admin

Click Admin (top right) to unlock editing: add/edit/delete units, loan/return/remove them, and add/rename/remove shelves and bay counts. The first time, you set the admin password. It stays unlocked in this browser tab until you lock it or close the tab.

Heads-up: the admin password is checked in the browser, so it keeps normal viewers out but isn't a bank-grade lock. Fine while there's no sensitive data — we can add real sign-in later.

💾 Saving

Everything saves automatically to the cloud and to this browser. No save button.
